# Data boundaries

Do not commit raw, private, client, account, credential, licensed, or restricted
market data. The committed CSVs here are small synthetic examples inherited from
the template or generated for this milestone; tests may also use synthetic fixtures.

Each market dataset needs an owner, source, license, schema version, as-of semantics,
timezone/calendar, units, adjustment policy, retention, and source hash.

`spot-vol-example.csv` is generated by `scripts/generate_synthetic_fixture.py`:
owner J. Myers; source synthetic-v1; project license; calibrated-iv/v1 schema;
explicit UTC instants and synthetic US-style sessions; price in artificial units,
annualized decimal IV; no adjustments; retained with the source revision. Its exact
hash is recorded by each replay. Four sessions with 30 endpoints each produce 112
accepted pairs after the opening-endpoint exclusion and session boundaries.

`example.csv`, `regression-example.csv` and `walk-forward-example.csv` are template
reference examples. Parquet publications belong in ignored `data/processed/`;
retain manifest and checksums with each version. Raw/private inputs belong under
ignored `data/raw/` or `data/private/`, with access governed by the source license.
